# Проект: Консольный менеджер задач

>ВАЖНО! Необходимо предварительно зайти в директорию проекта (команды cd и ls в помощь)

Запуск программы:

1) Создаем виртуальное окружение:

```bash
python3 -m venv .venv
```

2) Активируем виртуальное окружение (линукс):

```bash
source .venv/bin/activate
```

3) Запускаем приложение:

```bash
python main.py
```
